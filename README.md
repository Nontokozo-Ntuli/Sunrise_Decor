# Sunrise Decor - Event Decoration Website

Sunrise Decor is a professional event decoration website based in Durban, South Africa. We specialize in creating memorable experiences for weddings, birthdays, corporate events, and graduations.

**📍 Location:** 123 Florida Road, Durban, 4001

### ✨ Services
- Wedding Decor & Styling
- Birthday Parties
- Corporate Events
- Graduation Celebrations
- Custom Gallery & Reviews

### 💻 Website Features
- Responsive HTML5 & CSS3 design
- Gallery showcasing previous work
- Services page with pricing
- Enquiry and Contact forms
- Customer Reviews section

- CSS3
- GitHub Pages
