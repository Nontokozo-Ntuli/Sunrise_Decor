## Changelog

### Version 1.0.0 - 2026-10-28
Initial release of the Sunrise Decor website.

#### Added
- Responsive homepage with a modern event styling layout
- About page highlighting the brand story, mission, and values
- Services page showcasing wedding, birthday, graduation, and corporate event offerings
- Gallery page with event images and a lightbox-style display
- Reviews page with customer testimonials
- Enquiry form for quote requests and event information
- Contact page with contact details, address, and office hours
- Google Maps embed for the Durban office location
- FAQ section on the contact page
- SEO metadata for each page:
  - title tags
  - meta descriptions
  - keywords
  - Open Graph tags
  - Twitter card metadata
  - canonical URLs
- Favicon and logo asset setup
- Social media metadata for better sharing previews
- Local image asset management and file renaming for clearer project structure
- Mobile-friendly navigation with a responsive hamburger menu
- Accessibility mode toggle to improve readability
- Form validation improvements for required fields
- Optional message fields in contact and enquiry forms
- Clear user-friendly validation messages such as:
  - “Please complete the required fields before sending your enquiry.”
  - “Please complete the required fields before sending your message.”

#### Improved
- Navigation links were redesigned for better visibility and usability
- Header styling was refined to improve overall professionalism
- Mobile responsiveness for smaller screen sizes
- Image organization and file naming for better maintainability
- Contact page presentation by adding office hours and clear business details
- SEO and metadata implementation across all pages
- Form UX by reducing unnecessary restrictions and allowing optional messages

#### Fixed
- Duplicate map issue on the contact page by keeping only one map
- Map sizing and alignment for better layout on desktop and mobile
- Validation logic so only required fields trigger error messages
- Message field behavior so users are not forced to write more than they want
- Navigation layout issues on smaller screens
- Display consistency across different devices
