# Sunrise Decor

Sunrise Decor is a responsive event styling website for weddings, birthdays, graduations, and corporate events in Durban, South Africa. The site showcases the business’s services, gallery, customer reviews, enquiry form, and contact details.

## Overview

Sunrise Decor creates memorable celebrations by transforming ordinary spaces into vibrant, elegant, and unforgettable event experiences. This project is built using HTML, CSS, and JavaScript to provide a simple, mobile-friendly, and professional online presence.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Attractive home page with service highlights and call-to-action buttons
- About page with brand story and business background
- Services page with package information and filters
- Gallery page with event images
- Reviews page with customer testimonials
- Enquiry form for quote requests
- Contact page with address, email, phone, and office hours
- SEO-friendly metadata and social sharing tags
- Accessibility mode toggle for improved readability

## Local Setup

1. Clone or download the project files.
2. Open the project folder in your browser, or run it with a local web server.
3. Open `index.html` in a browser to view the website.

You can also use VS Code with Live Server for a smoother development experience.
